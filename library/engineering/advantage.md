# 工程卡：优势估计与归一化

由 `cards/pattern/*/` 各卡"工程经验"节与 `F5_stop_eval/engineering_lessons.md` 去重汇总（自动按关键词分组，一条只归一组）。括号内为原论文出处；行首为来源卡。

- `PC-F1-01` 当 λc 进入标量奖励且组为全对时，除 std 会把 λ 约掉，所以 λ=0.01 与 0.001 等价。应当先在 mean-only 下做 λ0/小 λ 对照，再谈系数（2502.04463 §5.4.1）。
- `PC-F1-01` 当用 mean-only 但 loss 仍按序列长度平均时，α=0 也可能出现缩短。应当先修 loss 分母再归因于奖励（2502.04463 AppG；2503.20783 Listing1）。
- `PC-F1-01` 当把 budget curriculum 和固定 MAX_TOKENS 分母一起用时，改预算就是改梯度尺度。应当把预算视作超参记录（2503.20783 pitfalls）。
- `PC-F1-02` 当叠加两级归一化时，先代数化简最终优势，再解释收益；完整等大组配总体 std 时，第二级是恒等变换（litscan:62297 lesson；2512.24330 lesson）。
- `PC-F1-02` 当用历史统计收缩基线时，非平稳策略下历史会过时，应当按 topic/阶段重置（2602.05165 pitfalls）。
- `PC-F1-03` 当辅助信号权重与 std 的先后顺序不明时，curriculum 可能整体无效。应当打印标准化前后的 λ（2607.16244 lesson）。
- `PC-F1-04` 当减少工具调用时，应同时报告各基准的准确率变化，并核对成本经 std 后的量级（2604.19749 lesson）。
- `PC-F1-06` 当用组内成功直答触发效率偏好时，应持续监测直答支撑，以及全对组 std 对折扣的抵消。不能只看平均调用下降（litscan:arxiv:2505.15436 lesson）。
- `PC-F1-07` 当按必要性收费时，边界要与当前策略同步，并分别报告搜索压缩与准确率损失。不能用较弱的文献基线掩盖 matched 对照（2605.29796 lesson）。
- `PC-F1-08` 当用固定教师判必要性并做组 std 时，应分别检验两件事：教师与学生的符号一致率，同结果组里幅度是否被抵消。不能只看平均准确率（litscan:58852 lesson）。
- `PC-F1-10` 当用分支差训练工具路由时，应把离线专家标签与在线 actor 信号分开记录。保留两支的采样支撑，再检查归一化是否删掉了分支常数成本。平均效用变好时，也要检查直答子集是否受损（2609.00967 lesson）。
- `PC-F1-10` 当用工具次数分层时，应先看每层有效样本数和跨层的策略变化，再调混合系数，不能只看 advantage 方差（2510.06214 lesson）。
- `PC-F1-11` 当单个决策 token 与长度差异很大的回答共用分母时，先算每种模式的实际决策梯度尺度，再调 α；同时检查两种模式的支撑（2505.13379 lesson）。
- `PC-F1-12` 当用频率校正防塌缩时，应检查它在 std 之后的实际作用，以及对未采样模式的覆盖；token 节省应与逐任务准确率、训练预算一并报告（2505.20258 lesson）。
- `PC-F1-12` 当混合任务把一种模式挤出时，先检查控制项经过 std 后是否还留有模式梯度（2607.08572 lesson）。
- `PC-F1-13` 记录 ratio 裁剪的对象、优势门控与 token 聚合方式。做小规模训练前，先用解析的二 token 反例核对所谓的 trust-region 保证（litscan:77605 lesson）。
- `PC-F1-15` 当引入外部过程分数来补全错组时，要明确门控与归一化的作用域，并用常数或打乱的过程信号排除长度与格式带来的伪奖励（2605.30451 lesson）。
- `PC-F1-16` 同状态 LOO 的局部统计意义清楚。落地前必须写清四件事：分叉点怎么选、路径怎么聚合、回报怎么折扣、真实算力怎么对齐（2607.14171 lesson）。
- `PC-F1-16` 当树拓扑改动看似有效时，先核对每个分支优势覆盖了哪些 token，再做相同 token 预算的拓扑对照（2609.20004 lesson）。
- `PC-F1-17` 基线与 loss 聚合要一起推导。先隔离三个因素：去 std、新鲜采样、长度加权（2505.23585 lesson）。
- `PC-F1-17` 用完整轨迹决定基线权重时，先做以下检查：自身权重、负余弦、零分母、动作依赖（litscan:61987 lesson）。
- `PC-F1-18` 代价尺度会被组 std 抵消时，先确认代价进入的是 reward 还是独立 loss；动态 λ 需要校准约束反馈（2310.12773 lesson）。
- `PC-F1-18` 加长度惩罚时，同时记录原始违背量、clip 比例和标准化后的优势（2512.21540 lesson）。
