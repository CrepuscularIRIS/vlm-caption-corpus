# 工程卡：数据、采样、课程与其他

由 `cards/pattern/*/` 各卡"工程经验"节与 `F5_stop_eval/engineering_lessons.md` 去重汇总（自动按关键词分组，一条只归一组）。括号内为原论文出处；行首为来源卡。

- `PC-F1-01` 当训练已锁死后，再切到 mean-only 不会恢复。应当在开训时就固定估计器（2607.21273 Appendix I）。
- `PC-F1-04` 当可不调用工具答对的题在训练集里不足时，即使有代价项也会学成普遍调用。应当先保留可验证的无工具成功样本（2506.20670 lesson）。
- `PC-F1-05` 当用历史最少成功数作锚时，应记录锚被单次成功更新的频率，以及是否有"更少调用的成功先受罚后更新"的顺序问题（2504.14870 OBJ.invariance：新成功 $m<n$ 若先更新 $n$ 可得满分，若先受罚则相反）。
- `PC-F1-05` 当只罚交互轮数时，浪费可能转移到批内调用。应当分别记录轮数、底层调用数、token 与耗时（2605.07177 lesson）。
- `PC-F1-07` 当用受控分支监督自由分支时，应把三种来源区分开：提示变化、采样噪声、梯度支撑收益（litscan:60137 lesson）。
- `PC-F1-08` 当用粗粒度视觉工具降成本时，应把以下几项分开验证：离线必要性伪标签、格式可解析性、是否取到证据、最终是否用上证据、端到端时延（2603.16932 lesson）。
- `PC-F1-08` 当可无工具答对的题不足时，代价项单独作用仍会学成普遍调用。应当先在数据里保留无工具成功题（2506.20670 lesson）。
- `PC-F1-09` 当用强制前缀保障分支覆盖时，应分别统计自然首决策和前缀之后的能力，避免把强制分支的成功当成 router 已恢复（2510.12838 lesson）。
- `PC-F1-09` 当直答采样消失时，先保住竞争分支，再测自然选择；固定偏好代替不了非劣检验（2505.13417 lesson）。
- `PC-F1-09` 当通过固定模板补动作支撑时，要另测自由决策下的迁移和直答保持（litscan:62146 lesson）。
- `PC-F1-11` 当专项 RL 破坏路由时，先做单决策 token 的 loss 消融，并区分"直接梯度屏蔽"与"参数冻结"（2505.11896 lesson）。
- `PC-F1-12` 当离散模式标签可能与真实计算脱钩时，先测模式之间的能力差（2608.20256 lesson）。
- `PC-F1-13` 当策略可以直答也可以看图时，先看分支支撑和区域多样性，再调工具频率；记录熵项覆盖哪些 token，以及额外的 token 成本（litscan:74479 lesson）。
- `PC-F1-15` 当训练需要特权帮助时，必须单独测量撤去帮助后的收益（2601.18779 lesson）。
- `PC-F1-17` 把统计指标当作优化器的门时，要分开三件事：总体恒等式、样本估计、实际 PG 性能（2604.19485 lesson）。
- `PC-F1-18` 用平滑代理训练约束策略时，对偶变量仍用真实约束统计；要明确代理的可行性与渐近时间尺度假设（1805.11074 lesson）。
- `PC-F1-19` 当探针显示信号可预测而工具行为仍错时，用轻量的输出干预检查执行层；同时保留真实收益与标签噪声的对照（2605.09252 lesson）。
- `PC-F1-19` 当隐藏分数受原决策类别和层尺度影响时，要分别校准，并用下游任务结果验证（2502.12961 lesson）。
- `PC-F2-01` 当反事实分支共享随机数时，应按语义位置同步 key 且不重用，并完整记录分支概率以做校正（2610.31544 lesson）。
- `PC-F2-01` 当二元终奖在全部分支上相同时，反事实差为 0，应回退或标 unknown，而不是当作"零价值"训练（2608.01667 §3）。
- `PC-F2-01` 当预算匹配只按 token 代理时，不能宣称严格同成本（2610.31544 pitfalls）。
- `PC-F2-03` 当 γ 很小时，长路径会触 eps 下限，应先算最大可分辨距离（2609.35084 AppD.2）。
- `PC-F2-05` 当只用总和约束训练分解器时，应把分解当作不可识别的代理，并用打乱或均匀分解做对照（2505.20732、litscan:23737）。
- `PC-F2-06` 当用同模型后见似然时，先验应取同状态的动作分布，而不是跨时间的轨迹均值（2603.08754 failure_boundary）。
- `PC-F2-07` 当用似然差做塑形时，先核终止修正与 token return，再测 teacher 对齐（litscan:73124 lesson）。
- `PC-F2-08` 训练用的 gap offset 是 .1，不等于诊断用的 .001（2607.13988 pitfalls AppA.1–2）。
- `PC-F2-10` 当缓存前缀 fork 时，应单独核对共享前缀的 loss 计权、未选分支的准确率缺失，以及总前向成本（litscan:75333 lesson）。
- `PC-F2-10` 当离线 gap 由某个固定模型与预览配置产生时，应把 checkpoint、预览分辨率、打分方式、候选 bank、阈值与 head 的读取位置一起锁定（2608.21762 lesson）。
- `PC-F2-11` 当正确的教师轨迹依赖学生做不到的精细定位时，只匹配终答是不够的；离线成功分组应当作带版本号的标签，记录其漂移，并保留直答支撑（2608.08907 lesson）。
- `PC-F2-12` 当以中间命题作局部 RL 单位时，必须同时记录终答出现率、工具率与块长度；高局部分数可以与不终止共存（litscan:63890 lesson）。
- `PC-F2-13` 当已有 MC 过程语料冗余时，先按来源筛选，并分清标注成本与训练成本，再用 held-out 阈值评 PRM（litscan:79235 lesson）。
- `PC-F2-13` 全局阈值应在 held-out 上优化，不能在测试标签上调（litscan:79235 pitfalls）。
- `PC-F2-14` 同图输入会使反搜 support 近 1，比裁图更容易通过门（2606.05784 pitfalls AppB.3）。
- `PC-F2-16` PRM 数值有不同量纲：sum 分与 min 变换后的总分不能直接比较（2504.15275 pitfalls）。
- `PC-F2-16` 驻留期间 Fine 仍占用，成本不能只计 UPDATE（2610.12060 pitfalls）；对裁图而言，成本应同时计次数与视觉 token。
- `PC-F2-16` 当用事后视觉引用集合分组时，先报每组支持与有效坐标更新的比例（litscan:73207 lesson）。
- `PC-F2-18` 进展标签必须可靠，随机图标签会导致退化（2610.18683 REL P36:2）。
- `PC-F2-19` 正文的 checkpoint 计数与附录口径不一致；附录 Eq25 的负面积与 Eq26 直接相加存在符号疑点（litscan:76529 pitfalls）。
- `PC-F2-20` 当使用似然差塑形时，先核终止修正与 token return，再测 teacher 对齐；不能把教师信心的提升称为当前策略需要的信息（litscan:73124 lesson）。
- `PC-F2-20` 当用共享图估值时，不能把数学上收敛当作估计正确（2609.35084 lesson）。
- `PC-F3-03` 当 RL 阶段换用难例题池时，SFT 中的无工具比例会被迅速侵蚀，应每步记录无工具比例（litscan:61931 Figure3）。
- `PC-F3-04` 当把模式选择与解题分阶段训练时，记录标签生成用的 checkpoint 与 prompt，标签会随训练过时（2512.16883 notes）。
- `PC-F3-05` 当用两条件成败打标签时，两条件必须是同一前缀、同一 prompt，否则差异混入 prompt 效应（2512.16883 notes：M13 注意不同 prompt 不是严格同观测分叉）。
- `PC-F3-05` 当成功率阈值规则允许"两者都为 0"时，会把不可救的题标成"需要看"（2602.06040 FAIL 字段），应单列 unknown。
- `PC-F3-07` 当做错误前缀续写偏好时，同时保留"已答对则偏好短答"的偏好对，否则直答会被续写挤掉（litscan:77773 EQ §2.4）。
- `PC-F3-08` 当教师与学生 tokenizer 不同时，不能用 token 索引直接拼接，丢弃最后一个 word 再续（litscan:76463 PIT）。
- `PC-F3-08` 当用自生成数据做冷启动时，监测熵，必要时混入强模型样本（litscan:77335 §4.1）。
- `PC-F3-09` 当做在线重启时，正确/错误前缀分开存，并与原题合并采样（2502.02508 SIG）。
- `PC-F3-09` 当重组样本时，o1 的 KL 在 Stage I 仍然保留，不是完全无梯度（litscan:77335 ROUTE）。
- `PC-F3-11` 当把离策略样本放进组内时，只对离策略 token 做 shaping；对 on-policy token 做同样 shaping 会降分（2504.14945 Table4）。
- `PC-F3-12` 当比较效率时，把 offline 提示生成与 correction 计算都计入成本（COND 字段："cost 包含 offline context"）。
- `PC-F3-13` 当用分阶段 schedule 保支持时，阶段切换是固定的，不是按边界事件自动切换（2604.22779 PIT）。
- `PC-F3-14` 当新行为早期弱时，先给正确恢复示范并屏蔽错误动作 loss，再观察是否错误调用拿探索奖（litscan:51030 LESSON）。
- `PC-F3-14` 当反馈信号来自 batch 统计时，用 EMA 加量化稳定，并注意量化后是否再 clip（2607.10738 notes）。
- `PC-F3-14` 使用率达标后，另行定义 0 vs 1 次的成本，率下限本身不提供这个方向（litscan:51030 LESSON）。
- `PC-F3-15` 当成功调用额外获奖时，必须单列"正确无工具"样本与冗余调用（litscan:79554 LESSON）。
- `PC-F3-16` 当用离线难度过滤时，记录过滤后题池中各来源比例与 direct_ok 比例；hard-only 会导致无工具行为几乎消失（litscan:61931 Figure3）。
- `PC-F3-17` 当用首次出现正确答案作截止点时，区分充分证据与碰巧猜中（litscan:71725 LESSON；与 P66 相关）。
- `PC-F3-18` 当用特权输入做自蒸馏时，先钉住教师，显式记录 GT 答案/区域与学生可见像素，并用信息消融排除"只靠答案提示"的解释（2606.08719 LESSON）。
- `PC-F3-18` 当 teacher 由当前 student 条件化而来时，直接同步容易放大概率扰动，用 EMA 稳住（litscan:75750 LESSON）。
- `PC-F3-18` 当只用初始策略的固定正确样本 SFT 仍遗忘时，试逐轮刷新采样，并同时追踪原能力、目标收益和采样总量（litscan:76009 LESSON）。
- `PC-F3-19` 当用回放抵抗遗忘时，按任务数增长的回放容量要计入成本（litscan:77971 FAIL）。
- `PC-F3-20` 当 teacher 能直接看到目标而 student 不能时，优先用 teacher 状态评价 student 的采信息动作，不直接蒸馏跳过观察的 expert 动作（2512.01188 LESSON）。
- `PC-F3-20` 当主动观察改变后续状态时，同时记录从该状态出发的可执行动作，单换图片不够（2610.23378 LESSON）。
- `PC-F4-01` 工具奖用 max 聚合时**：重复调用不受罚。另需重复/冗余惩罚（2604.19945 degenerate_cases；litscan:63682 penalty 消融 60.1→55.9）。
- `PC-F4-01` 混入未增广的 canonical 数据时**：模型会学 index0 捷径。应在工具阶段只用增广数据（2604.19945 App.D.3：DocVQA-RF 67.1→79.4，工具调用 6.98→4.26）。
- `PC-F4-02` 出现"调用先升后降"时**：不能把后期下降解读为学会了按需（litscan:72124 failure_boundary）。
- `PC-F4-03` 用成功共识作伪标签时**：要单独消融"探索"与"共识奖"，检查自身投票、fork 相关性、空集与单成功分支（litscan:71995 lesson）。
- `PC-F4-03` 用相对面积时**：要同时检查 direct 分支实际收到什么信号，以及各通道为空时的 fallback（litscan:63255 lesson：无正确样本时 r 为 0/0，无成功正确裁图时面积均值为空）。
- `PC-F4-04` 用现成 LVLM 打分前**：先在人工核验的图文步骤上，按正/错类和工具错误类分别测，并说明前缀与 GT 的可见性（2602.08346 lesson）。
- `PC-F4-06` 去图 span 时**：要干净删除并保持同一文本位置的对应。负 VIG 来自无图分布外输入和数值误差；clip 只是把值限定在区间内，不能修正负值（2608.21883 pitfalls）。
- `PC-F4-06` 缓存前缀分叉时**：单独核对共享前缀的 loss 计权、未被选中分支的 accuracy 缺失，以及总前向成本（litscan:75333 lesson：Table5 含开销为 86.3%，不是省 25%）。
- `PC-F4-07` 用 token 筛选节省监督时**：保留完整上下文作为输入，只去掉低分 token 的 CE 项；单独统计打分与训练的总时间；保护工具格式、stop 与纠偏的支撑（litscan:79376 lesson）。
- `PC-F4-08` 平均的是概率差，不是 logits 后再 softmax（2608.06270 conditions）；
- `PC-F4-10` 中间通道被宣称有推理价值时**：同时测内容替换、oracle 上限和等步数 pause，并记录格式失败与补全协议（2605.18445 lesson）。
- `PC-F4-10` 评估 recover 时**：必须检验答案关键视觉事实是否改变，不能用"再裁图动作次数"代替（litscan:73853 relevance P50）。
- `PC-F4-11` 用盲读者路由失败信用时**：先检查混合 A 的符号与代理假阴性，并区分文本充分性、视觉事实、工具必要性三者（litscan:78739 lesson）。
- `PC-F4-11` recognition 跨度与 tag 异常的 fallback**：必须实现时核对（litscan:78739 pitfalls）。
- `PC-F4-11` 文本推理者缺特定视觉事实时**：先用等预算的反馈负对照与事实核查验证收益，不能把更高信心当作必要裁图的标签（2510.25092 lesson）。
- `PC-F4-13` 用语言一致性约束视觉训练时**：加入正确/错误提示交叉，以及空 reasoning 对照（litscan:73751 lesson）。
- `PC-F4-13` caption 历史可能有错时**：保留"去历史、同一张图"的对照，并单独测必须依赖历史的问题（litscan:2420 lesson）。
- `PC-F4-13` 构造增广文本的模型只读了题目和指定答案时**："正确 caption"可能直接泄露标签（litscan:73751 AppC pitfalls）。
- `PC-F4-14` SFT 监督了证据与答案一致、RL 只保结果时**：一致性可能退化，需要单独记录，不能用正确率代替（litscan:72973 lesson）。
- `PC-F4-14` 当显式坐标损伤答案时**：可以把 grounding 留在训练参照通道，但必须独立审计参考事实（litscan:77580 lesson）。
- `PC-F4-15` 把现成 LVLM 接成裁图过程打分器时**：先用人工核验的图文步骤分开测正类、错类和工具错误检出，并写清前缀与 GT 的可见性（2602.08346 lesson）。
- `PC-F4-15` 自评用于搜索时**：要对照 token 预算和评估器错误的相关性（litscan:2952 lesson）。
- `PC-F4-17` 当新增文字导致视觉回答退化时**：先用"重复问题"对照拆出 prompt 本身的收益（litscan:77320 lesson）。
- `PC-F4-18` 按能力分阶段训练时**：用等步数的 merged 训练和交换顺序做检验（litscan:76396 lesson）。
- `PC-F5-01` 当用 token 预算控制时，它不等于工具调用或视觉 token 成本，应分别计量（2503.04697 pitfalls）。
- `PC-F5-04` 当用 oracle 强制停止训练时，测试必须撤掉强制，且不能把 oracle 辅助的结果与自主策略结果混报（litscan:1210 pitfalls）。
- `PC-F5-05` 当用 hindsight 最佳未来答案构造停止标签时，部署特征不得含未来信息（2610.05400 pitfalls）。

- `PC-F5-05` 当停止监督来自证据覆盖或终局结果时，要检查决策输入与标签的时间下标（2604.17866 lesson，见 PC-F5-06）。

- `PC-F5-07` 当熵阈值作为超参时，先核其取值范围是否与候选数一致（litscan:77776 lesson、pitfalls）。
- `PC-F5-08` 当用搜索评估所有动作时，评估成本不等于执行成本，二者要分开列（2607.16981 pitfalls）。
- `PC-F5-09` 当比较 SFT 与 RL 时，要把教师失败生成和配置搜索成本计入总算力（2507.04103 lesson）。
- `PC-F5-11` 当把向量注入输入 embedding 时，同维度不等于同尺度，应按初始 embedding 平均 L2 范数校准（2606.01287 pitfalls）。
- `PC-F5-11` 当结构目标需前移一位对齐时，latent/image 位置的 label 设为 ignore，边界 marker 保留 CE（2606.01287 pitfalls）。
- `PC-F5-12` 当用 chosen 回答当 correct、用自动答案一致性过滤时，它不等于逐条视觉事实的人工验证（litscan:77236 pitfalls）。
- `PC-F5-13` 当同题不同初始视图被当成多题时，它们不独立，样本量要按题计（litscan:2777 pitfalls）。

- `F5-lessons` 当强制作答前缀以未闭合 `<think>` 的第一人称文字实现时，它可能被误当作策略动作训练，应当核对它在 loss 中是 prompt 还是 action。（2607.14547 signal_routing）
