## 操作
把外部资源上限 $B$（目标 token 数 / 每工具剩余次数 / 最大交互轮次 $T_{max}$ / 墙钟时间）作为输入放进策略上下文，训练或提示策略在该条件下生成；训练时对 $B$ 采样，使同一策略覆盖多档预算。AdaTurn 的状态写法：$x=(Q,I,T_{max})$，$h_t=(Q,I,T_{max},(y_1,o_1),\dots)$，且 $t<T_{max}$ 时动作集为 工具∪答案，$t=T_{max}$ 时只剩答案（2607.14547 Eqs1–5 p.4）。

## 信息
- 策略能看到：预算数值（以及已用量），历史与观测。看不到：真值、剩余证据的价值、自己是否已足够。预算是外部资源，不是必要性标签（2607.14547 Sec3.3 p.6 的 information 字段）。
- 由谁估计：无估计器；只是条件输入。是否学会"按预算分配"取决于训练奖励（L1 用正确性 + 长度偏差；AdaTurn 只用正确性；Timely 用超时归零 + 时间利用率）。

## 成立条件
- 预算真实提供，且执行器与模型的轮次计数一致（2607.14547 Sec3.3 conditions）。
- 训练覆盖多档预算；外推到训练外预算需单独验证（AdaTurn 训练 4–12、推理到 16–32，2607.14547 Sec3.3）。

## 成功条件 / 失败模式
- 成功条件：预算在训练中被采样且奖励里有与预算相关的项（L1 的长度项、Timely 的超时归零）或有边界强制（AdaTurn）。
- 失败模式：
  - "有预算意识"不等于"少用"：BATS 的目标是预算内更强，不一定减少调用；同预算下 BT 比 ReAct 更贵（2511.17006 Table2 / failure_boundary）。
  - 按时完成 ≠ 正确（2601.16486 Table2：按时 53.3、正确 33.3）。
  - 预算外推与 OOD 误差大（2503.04697 Table2 p15）；更低预算牺牲准确率（2503.04697 Table1 failure_boundary）。
  - L1 Exact 目标可奖励"错但长度贴近"的输出，会凑长度（2503.04697 objective.invariance/degenerate_cases）。
  - AdaTurn 的增益来自整套方法，预算输入本身没有单独消融；未报实际平均调用数/终止率（2607.14547 Sec3.3 failure_boundary）。
  - token 预算 ≠ 工具延迟/视觉 token，不能把总长度变短当少 crop（2503.04697 pitfalls）。
- 外部佐证（非成员）：固定 7 轮比按需早停更慢更差，M3CoT 45.7/24.34s vs 固定 7 轮 42.7/72.48s（litscan:78777 Table2，F3 digest）。

## 审稿期望
- 同时报授予预算、实际调用数和 token/费用（2511.17006 lesson；2503.04697 lesson：报真实长度、误差分布与准确率）。
- 预算输入需单独消融，不能只报整套方法（推断，自 2607.14547 failure_boundary）。
- 多训练种子与区间（推断：四篇都没有训练种子区间）。

## 认知障碍
事后截断会打断推理，预算必须进入训练才能被策略利用（2503.04697 why_non_obvious）；同一预算不等于同一实际成本（2511.17006 why_non_obvious）；最后一轮动作空间从"继续/回答"变为"只能回答"，预算盲策略会在出答案前被截断（2607.14547 why_non_obvious）。前人多把预算当外部截断而非状态变量。

## 工程经验
- 当 rollout 中各请求预算不同时，慢引擎会卡住整个 batch，应按预算降序、分给累计预算最小的引擎并在结束后按原索引恢复顺序（2607.14547 Algorithm1 p.14；Fig5 报 rollout 生成平均 1.34×）。
- 当用 token 预算控制时，它不等于工具调用或视觉 token 成本，应分别计量（2503.04697 pitfalls）。
