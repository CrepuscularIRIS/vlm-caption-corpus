## 操作
本卡是负面模式，描述"在结果奖励之外为工具行为加正分"会发生什么。

各论文的加分方式：

| 论文 | 加分对象 | 出处 |
|---|---|---|
| VLM-R3 | 答对时，每个有效框额外加分，上限 0.5 | litscan:52749 Eq4 |
| 2506.14821 | 成功执行 zoom 得 $\gamma=0.1$ | §2 Reward shaping |
| Ophiuchus | 答对时给工具奖励 2；附录 Eq7 漏写了工具条件 | litscan:78361 AppC Eq4–7 |
| DeepLatent | 附录中的 latent 调用奖励 | 2606.00562 AppA.2 |
| ATLAS | 功能 token 使用奖励 $r_{func}$ | 2605.15198 §2.2 |

另外几篇提供的是对照证据，而非加分方案：
- 只用结果奖励（2605.07177 Table5）。
- 不加任何调用惩罚（2507.13348 Fig.3；2506.20670 Fig5b）。
- 正 $\Delta S$ 时奖励随调用次数升到 $n_{max}$（litscan:58852 Eq2–3）。
- 工具 bonus 对照（litscan:74479 Table2）。

## 信息
- 整条轨迹是否调用、调用是否可执行、框是否有效、最终是否正确。
- 看不到：这次调用是否必要。
- 由谁估计：规则计数。

## 成立条件
**在这些条件下会膨胀**
- 正分与调用次数单调相关，或只区分 0 次与至少 1 次（litscan:52749 degenerate_cases："有效 crop 奖励只区分 0 与至少 1，不能惩罚冗余"）。
- 数据中缺少"不调工具就能答对"的题（2506.20670 Fig5b 与 Table9 子集说明）。

**反过来**
- 在全量含易题的数据上，即使有小额工具奖励，模型仍学会不调工具（2506.14821 §2 Data mix 引文）。
- 所以方向由数据组成决定，奖励只是放大器。

## 成功条件 / 失败模式
**成功条件（作为"教会调用"的手段）**

**失败模式（本卡的主要内容）**
- 调用膨胀，准确率不升或下降，见上表的反例行。
- 奖励曲线升高不能当作效率证据（2506.20670 negative_results：消融变体奖励更高，但 SR 近 100%）。
- 奖励投机：出现无意义的块或功能 token（2606.00562；2605.15198）。

## 审稿期望
- 推断的要求：
  - 凡带工具正奖励的方法，必须报告逐基准调用率与准确率的配对变化；
  - 必须有"去工具奖励"消融。

## 认知障碍
- 把"调用率高"当成"学会了用工具"。DeepLatent 与 DivFreq 都显示，调用次数增长不等于能力增长（2606.00562 lesson；litscan:74479 why_non_obvious）。

## 工程经验
- 当论文以"region-conditioned"命名时，应核对真实优势是否分步骤，以及有效框奖励是否只是在鼓励调用；工具像素必须作为环境状态 mask 掉（litscan:52749 lesson）。
- 当提高中间视觉表示质量时，要把触发次数与有效内容分开；不能用额外的调用奖励把次数增长当作能力增长（2606.00562 lesson）。
- 当操作 token 只占少量输出时，要联合核对使用奖励与计数惩罚（2605.15198 lesson）。
