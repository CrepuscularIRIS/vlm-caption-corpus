## 操作

用一个**冻结**的读者（初始化模型、外部教师或参考模型）在每个工具边界读完整前缀（含工具输出），teacher-force GT 答案，得到信息量：

- TRACE：$\bar\ell_k=|y^*|^{-1}\sum_t\log\pi_{ref}(y^*_t|S_k,y^*_{<t})$，$d_k=-\bar\ell_k+\epsilon$，$\delta_k=\log(d_k/d_{k+1})$。K=3、γ=.8 窗口平均，最后一轮补 $\lambda_{term}\gamma^{T-k}A^{out}$，再 $\hat A_t=A^{out}+0.2\,r^{turn}$（2607.13988 Eqs5–11）。
- IG-OPD：冻结 teacher 在学生检索前后的历史上为金答案打分，按 |IG| 分配逐轮蒸馏监督，并只在 query action token 上加有符号 IG（2610.20664 签名）。
- CIGAsk：冻结参考模型在"有/无用户回复"两种上下文下的 GT 对数似然比，作内在奖励；与 terminal 奖励分别 z-score 后相加（2609.24290 签名）。

## 信息

- 看得到：完整前缀（含工具返回）、GT 短答案、冻结读者的 logprob。
- 看不到：当前策略在该状态的真实收益；读者与策略之间的能力差。

## 成立条件

- 冻结读者对 GT 的"可读性"要能代表当前策略的需要；记录明确说这只是读者可读性，不是策略的因果收益（2607.13988 why_non_obvious）。
- 工具交互可识别边界，环境 token 要 mask（2607.13988 signal_routing）。

## 成功条件 / 失败模式

- 成功：读者与策略能力相近、同族；任务目标是"多做有用交互"（如深度搜索）。
- 失败：
  - TRACE 鼓励更长的交互，**不省工具**（2607.13988 failure_boundary）；Fig5 最大设置 28.9 低于 GRPO 30（横轴与标题冲突，2607.13988 negative_results）。
  - CIGAsk 在清楚的 query 上仍有 26% 澄清，即 when 控制不干净（2609.24290 Table3）。

## 审稿期望

TRACE 为 reviewer_concern=low_evidence。"推断"：
- 必须给"读者 = 当前策略"的对照；
- 报告读者与策略在同状态上的一致率；
- 报告工具调用数，而不只报准确率。

## 认知障碍

- 同等的绝对 logprob 提升，按剩余 gap 相对化后更有区分度；但这仍只是冻结读者的可读性（2607.13988 why_non_obvious）。
- 把"局部澄清带来的信息"与"是否发起澄清"拆开；冻结代理稳定，但不等于当前策略真实的动作价值（2609.24290 why_non_obvious）。

## 工程经验

- 当加入冻结读者信号时，应把结果优势（含 std）与稠密信号的原尺度分开记录，并核对实际使用的窗口与 token 加权是否破坏了端点定理（2607.13988 lesson）。
- 训练用的 gap offset 是 .1，不等于诊断用的 .001（2607.13988 pitfalls AppA.1–2）。
